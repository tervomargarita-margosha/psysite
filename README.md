# Сайт психолога Маргариты Терво

## Как добавить новую статью

1. Создайте файл в папке `_posts/` с именем:
   `ГГГГ-ММ-ДД-название-латиницей.md`
   Например: `2025-02-15-kak-spravitsya-s-trevogoy.md`
   (дата — для сортировки; URL статьи будет `/articles/kak-spravitsya-s-trevogoy/`)

2. Внутри файла напишите:

   ```markdown
   ---
   title: "Заголовок статьи"
   description: "Короткое описание для поисковиков (1-2 предложения)"
   date: 2025-02-15
   # image: /images/article-trevoga.jpg   ← опционально, превью-картинка
   ---

   Текст статьи в Markdown.
   
   ## Подзаголовок
   
   Обычный абзац. **жирный**, *курсив*, [ссылка](https://example.com).
   
   - список
   - пунктов
